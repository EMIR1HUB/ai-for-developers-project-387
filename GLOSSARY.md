# Запись на звонок

Сервис, где владелец публикует время для встреч, а гость бронирует его под выбранный тип встречи. Английское имя в скобках используется в коде и контракте.

## Участники

**Владелец** (_Owner_):
Единственный хозяин календаря, заданный заранее. Заводит типы встреч и видит все бронирования.
_Избегать_: хост, админ, организатор

**Гость** (_Guest_):
Человек без учётной записи, который бронирует слот, указав имя и email.
_Избегать_: клиент, пользователь, посетитель

**Профиль владельца** (_Owner profile_):
Имя, подпись и часовой пояс владельца, которые видит гость.
_Избегать_: аккаунт, пользователь

## Календарь

**Тип встречи** (_EventType_):
Шаблон встречи владельца с названием, описанием и длительностью. После создания не меняется и не удаляется.
_Избегать_: тип события, услуга, сервис

**Идентификатор типа встречи** (_Event type id_):
Короткое имя типа встречи, которое владелец задаёт при создании. Уникально и не меняется.
_Избегать_: slug, код, ключ, ссылка

**Бронирование** (_Booking_):
Интервал времени, занятый гостем под конкретный тип встречи. После создания не меняется и не отменяется.
_Избегать_: встреча, запись, бронь, звонок

**Заметка** (_Note_):
Необязательный текст гостя к бронированию для владельца.
_Избегать_: комментарий, сообщение

**Предстоящее бронирование** (_Upcoming booking_):
Бронирование, которое ещё не закончилось, в том числе идущее прямо сейчас.
_Избегать_: будущая встреча, активная запись

**Слот** (_Slot_):
Интервал длиной в длительность выбранного типа встречи, который гость может забронировать. Слот **занят**, если пересекается хотя бы с одним бронированием любого типа.
_Избегать_: окошко, таймслот

**Окно записи** (_Booking window_):
Скользящий период из 14 календарных дней начиная с сегодняшнего по часовому поясу владельца, в пределах которого гость может бронировать.
_Избегать_: период, горизонт

**Рабочие часы** (_Working hours_):
Ежедневный интервал времени, в который владелец принимает встречи. Слот целиком лежит внутри рабочих часов.
_Избегать_: расписание, доступность

**Часовой пояс владельца** (_Owner time zone_):
Пояс, в котором заданы рабочие часы и считаются дни окна записи; всё время в сервисе показывается в нём.
_Избегать_: местное время, серверное время

## Страницы

**Главная страница** (_Home page_):
Страница, которая рассказывает о сервисе и ведёт гостя в каталог типов встреч.
_Избегать_: лендинг, стартовая страница

**Каталог типов встреч** (_Event type catalog_):
Страница, где гость видит владельца и все типы встреч и выбирает один из них.
_Избегать_: страница записи, список событий

**Страница бронирования** (_Booking page_):
Страница одного типа встречи, где гость выбирает день и свободный слот и оформляет бронирование.
_Избегать_: страница записи, календарь

**Админка** (_Admin_):
Раздел владельца для создания типов встреч и просмотра предстоящих бронирований.
_Избегать_: панель управления, кабинет
