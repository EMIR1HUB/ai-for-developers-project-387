# Ошибки API передаются стандартными HTTP-статусами

API сообщает об ошибках кодом ответа, а не полем в теле при `200`: `409 Conflict` с `{ code: "SLOT_TAKEN", message }` для занятого слота, `422` с описанием полей для ошибок валидации, `404` для неизвестного типа встречи. Это сознательное отступление от правила «всегда HTTP 200», принятого в банковских сервисах автора: здесь единственный клиент — SDK от Hey API, который отличает успех от ошибки именно по статусу.
